# BBUnity

## Update 23/11/2026

BBUnity has been brought into a single library: [BBUnity](https://github.com/bigbearstudios-unity/BBUnity) which is currently undergoing large changes to reach v1.0.0.

All of the previous libraries have been archived but are still avaliable.

### Previous Libraries

- [BBUnity Core](https://github.com/bigbearstudios-unity/core) - The core library with helpers / base classes which power the other libraries
- [BBUnity Core2d](https://github.com/bigbearstudios-unity/core2d) - The core library with helpers for 2D environments
- [BBUnity SpriteAnimator](https://github.com/bigbearstudios-unity/sprite-animator) - A simple sprite animator with a single dependency of the Unity Sprite class
- [BBUnity Validation](https://github.com/bigbearstudios-unity/validation) - Collection of type validators, a core dependency of our UI forms library
- [BBUnity Conversion](https://github.com/bigbearstudios-unity/conversion) - Collection of type conversions
- [BBUnity State Machines](https://github.com/bigbearstudios-unity/state-machines) - A set of state machines, a core dependency of our Entities library
- [BBUnity Pools](https://github.com/bigbearstudios-unity/pools) - A set of object pools
- [BBUnity Events](https://github.com/bigbearstudios-unity/events) - An event listener / caller library
- [BBUnity Gameplay](https://github.com/bigbearstudios-unity/gameplay) - A set of game play focused classes. Currently includes: RPG Statistics
- [BBUnity Entities2d](https://github.com/bigbearstudios-unity/entities2d) - A set of entities which are focused around 2d gameplay
- [BBUnity Test Support](https://github.com/bigbearstudios-unity/test-support) - Support classes to help with testing, a core dependency of the other libraries
